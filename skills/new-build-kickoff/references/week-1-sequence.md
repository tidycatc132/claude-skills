# Week 1 sequence

`<slug>-setup-checklist.md` lists these steps in this order, as `- [ ] ` items with the owner in parentheses. `check_kickoff.py` checks each step title appears, in order.

1. Run the New Build Kickoff (AM)
2. Set up the Claude Project (AM)
3. Review the gap questions (AM)
4. Send the welcome email with the intake form link (AM)
5. Process the intake form answers (AM)
6. Confirm platform access (Dev)
7. Generate the Kickoff Call brief (AM)
8. Kickoff Call (AM)
9. Process the Kickoff Call transcript (AM)
10. Build the Client Reference Kit (SEO)
11. Topic research and sitemap creation (SEO)
12. Generate the homepage content brief (SEO)
13. Produce homepage content (SEO)
14. Human editorial review (SEO editor)
15. Generate the design brief (Design)
16. Design produces 2-3 homepage options (Design)
17. Send the Week 1 email to the client (AM)
18. Process client feedback (AM, when it arrives)
19. Week 1 handoff check (AM/PM)

When the SOW includes paid media, add one item right after step 3: `- [ ] Send the paid media brief to Paid Media (AM)`.

Under step 2, add these sub-items: name the Project `<Client Name> — New Build`; paste `<slug>-project-instructions.md` as the Project Instructions; upload the other kickoff files, the Sales transcript(s) and the SOW.

Under step 6, add: anything missing after the intake form goes on the Kickoff Call agenda.
