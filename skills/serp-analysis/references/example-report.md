# SERP Analysis: Example Report

A complete example output showing the expected format for a SERP analysis. In a real run, every metric also carries its evidence label (Measured, User-provided, Calculated, Estimated, Proxy or Unknown), its source and its observation time.

## Prompt

**User**: "Analyze the SERP for 'how to start a podcast'"

### Why #1 Ranks First

Buzzsprout's guide succeeds because it is:
1. **Comprehensive**: covers every step in detail
2. **Updated**: current year in the title, recent updates
3. **Structured**: clear numbered steps (owns the featured snippet)
4. **Authoritative**: a podcast hosting company (topical authority)
5. **Supported**: links to detailed sub-guides

### Featured Snippet Opportunity

**Current format**: Ordered list (steps)
**Current holder**: Buzzsprout

**To win the snippet**:
- Create a cleaner, more scannable list
- Keep it to 8-10 steps at most
- Start each step with an action verb
- Include "how to start a podcast" in an H2

### AI Overview Analysis

**Sources cited**:
1. Buzzsprout - "Choose your podcast topic"
2. Spotify for Podcasters - "Record and edit"
3. Wikipedia - Definition of podcasting

**Pattern**: The AI pulls step-by-step instructions from clearly structured guides

### Content Requirements

To rank on page 1:
- **Word count**: 5,000+ words minimum
- **Format**: Step-by-step ultimate guide
- **Backlinks**: 500+ from relevant domains
- **Updates**: Must show the current year
- **Unique angle**: Equipment comparisons, cost breakdowns, or a specific niche focus

### Recommended Strategy

Given the high difficulty, consider:
1. Target the long tail: "how to start a podcast for free" (Difficulty: 45)
2. Target a niche: "how to start a podcast about [topic]" (Difficulty: 30)
3. Create supporting video content for the video carousel
4. Focus on PAA optimization for quick wins
