# New Garage Door Installation in Boise

A new garage door changes how the front of a house looks and how warm the garage stays. We measure, supply and install steel, insulated and carriage-style doors.

## Choosing a door

We bring samples to your driveway and explain insulation ratings, window options and colours in plain words.

## Installation day

Most installations take one day. We haul the old door away and check the opener before we leave. Thinking about [a new opener](/services/opener-installation/) as well? We can fit both on the same visit.
