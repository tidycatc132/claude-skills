# Garage Door Opener Installation and Repair

An opener that grinds, reverses for no reason or will not respond to the remote can often be repaired. When it cannot, we install a quiet belt or chain drive opener.

## Repair or replace

We test the safety sensors, the force settings and the remote first. If the motor has failed, we explain the options and the price.

## Smart openers

Ask for phone control and we will set it up before we leave. Fitting a [new garage door](/services/garage-door-installation/) too? We can do both together.
