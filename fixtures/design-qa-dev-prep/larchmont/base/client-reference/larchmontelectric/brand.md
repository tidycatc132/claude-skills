# Brand: Larchmont Electric

## Positioning

Licensed residential electricians for Larchmont and New Rochelle homes. Panel upgrades, EV chargers and repairs, done by the same two-person crew from quote to inspection.

## Colours

- Navy `#1B2A41`: headings, the header and the footer
- Amber `#F2A900`: calls to action only, never for text or backgrounds
- Slate `#5B6770`: body text
- White `#FFFFFF`: page background

## Typography

- Headings: Barlow, semibold and bold
- Body: Inter, regular and semibold

- `larchmont-electric-logo.svg`, navy on white; a white version for the footer.
